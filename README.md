# 学情さん
### *新潟大学の学務情報システムのログインを二段階認証を含め自動化するスクレイピングツールです．*

↓↓以下のリンクからダウンロードしてください．↓↓  
*https://github.com/suikamin/gakujosan/releases/tag/v1.0.4*

新潟大学向けに開発されたCampusSquare（学務情報システム）以外での動作は保証しません．

初回起動までに、  
・学籍番号  
・パスワード  
・二段階認証の秘密鍵  
を準備してください．
  
起動すると、学籍番号、パスワード、二段階認証用の秘密鍵を入力するウィンドウが表示されます．事項を入力すると次回以降、その情報をもとに自動でログインが行われます．  
入力した情報を変更したい場合は、main.exeがあるファイルのなかの何もない場所で右クリックして「ターミナルで開く」の後、
```
.\main.exe -r
```
を実行してください．

ここで入力された情報は *config.json* としてローカルに保存され、外部に送信されることは一切ないことを保証します．  
このファイルはパスワードや秘密鍵が含まれます．隠しファイルにしてありますが、厳重に管理してください．  
このツールによって作成された *config.json* によって発生した不利益に関しては一切の責任を負いかねます．

また、入力した情報が保存されているファイルを削除したい場合は同様に、
```
.\main.exe -c
```
を実行してください．

すでに二段階認証の設定をしていて、秘密鍵を紛失してしまった場合、GoogleAuthenticatorから確認することはできませんので、二段階認証の設定をリセットし、秘密鍵を再発行してください．  
https://www.iess.niigata-u.ac.jp/acpb/upload/20231016105024000213600.pdf  
このサイト↑の４ページを参考にしてください．

このツールはPythonによってplaywrightとpyotpが使用され、pyinstallerでonedir化されています。
